# Shared public UI

This repository is the canonical source of CCI admin components, themes and API adapters.
Keep shared components common to Free and Pro products. Preserve the existing UI and accessibility behavior.
Do not add license verification, signing material or premium feature implementations to this repository.
Products import versioned packages; do not add aliases to sibling source repositories.
Run npm test and npm run release to validate changes and prepare local npm archives.
Do not publish, tag or upload a release as part of an ordinary build.
